根本原因是 ATA 硬盘控制器的 端口 0x1F6（Drive/Head 寄存器） 配置错误。

  问题链条

  端口 0x1F6 应写入 0xE0（LBA 模式），但代码写入了 0x00：

  ; 原代码
  mov al, ch          ; ch = 0（shl ecx, 16 后的值）
  and al, 0b1110_1111 ; 结果还是 0x00
  out dx, al          ; 写入 0x00 → ATA 控制器回退到 CHS 模式

  CHS 模式下扇区号是 1-indexed，产生 off-by-one 偏移：

  ┌───────────────────────────────────────┬─────────────────────────────────┐
  │               代码意图                │            实际效果             │
  ├───────────────────────────────────────┼─────────────────────────────────┤
  │ boot.asm 读 LBA 2（setup.bin 在 LBA   │ CHS 扇区 2 = LBA                │
  │ 1）                                   │ 1，歪打正着读对了               │
  ├───────────────────────────────────────┼─────────────────────────────────┤
  │ setup.asm 读 LBA 3（kernel.bin 在 LBA │ CHS 扇区 3 = LBA                │
  │  3）                                  │ 2，读到了空数据                 │
  └───────────────────────────────────────┴─────────────────────────────────┘

  结果： 0x1200 地址处是全零而非内核代码 → CPU 执行 00 00（add [eax], al）→
  triple fault → QEMU 重置 → BIOS 重启 → 循环闪烁。

  修复内容

  1. 端口 0x1F6 写入 0xE0（启用 LBA 模式）
  2. boot.asm 扇区号从 2 改为 1（LBA 1 才是 setup.bin）
  3. boot.asm 读取扇区数从 2 改为 1（setup.bin 不到 512 字节）
