# 串口驱动代码详解

## 概述

本文档详细解释串口驱动代码的每个部分，帮助你理解如何从零开始编写硬件驱动。

---

## 1. 硬件基础

### 1.1 什么是串口 (UART)

串口（Serial Port）是一种**异步串行通信**接口，通过一根线逐位发送数据。

```
CPU ──→ UART芯片 ──→ 串口线 ──→ 终端/调试器
         (16550A)
```

### 1.2 COM1 端口地址

x86架构中，COM1 使用固定的 I/O 端口：

| 端口 | 名称 | 功能 |
|------|------|------|
| 0x3F8 | THR/RBR | 发送/接收数据 |
| 0x3F9 | IER | 中断使能 |
| 0x3FA | IIR | 中断标识 |
| 0x3FB | LCR | 线路控制 |
| 0x3FC | MCR | MODEM控制 |
| 0x3FD | LSR | 线路状态 |
| 0x3FE | MSR | MODEM状态 |
| 0x3FF | SCR | 暂存寄存器 |

---

## 2. 端口 I/O 操作

### 2.1 为什么需要特殊指令？

x86 有两种地址空间：
- **内存地址空间**（0-4GB）- 普通内存访问
- **I/O 地址空间**（0-65535）- 硬件设备寄存器

串口使用 **I/O 地址空间**，需要特殊指令访问。

### 2.2 内联汇编实现

```c
// 写端口：outb(value, port)
static inline void outb(unsigned short port, unsigned char value) {
    __asm__ volatile("outb %0, %1" : : "a"(value), "Nd"(port));
}
```

**逐行解释：**

| 部分 | 含义 |
|------|------|
| `__asm__` | GCC 内联汇编关键字 |
| `volatile` | 禁止编译器优化，确保每次执行 |
| `"outb %0, %1"` | 汇编指令：outb value, port |
| `: :` | 输出操作数 : 输入操作数 |
| `"a"(value)` | 将 value 放入 AL 寄存器 (%0) |
| `"Nd"(port)` | 将 port 放入 DX 或 8位立即数 (%1) |

```c
// 读端口：value = inb(port)
static inline unsigned char inb(unsigned short port) {
    unsigned char value;
    __asm__ volatile("inb %1, %0" : "=a"(value) : "Nd"(port));
    return value;
}
```

**约束说明：**
- `"a"` = AL/AX/EAX 寄存器
- `"=a"` = 输出到 AL
- `"N"` = 0-255 的常量（用于 8位立即数优化）
- `"d"` = DX 寄存器

## 3. 串口初始化

### 3.1 初始化流程

```c
void serial_init() {
    // 1. 禁用中断
    outb(SERIAL_PORT + 1, 0x00);
    
    // 2. 设置波特率
    outb(SERIAL_PORT + 3, 0x80);  // 设置 DLAB=1
    outb(SERIAL_PORT + 0, 0x01);  // 除数低字节
    outb(SERIAL_PORT + 1, 0x00);  // 除数高字节
    
    // 3. 设置数据格式
    outb(SERIAL_PORT + 3, 0x03);  // 8N1
    
    // 4. 启用 FIFO
    outb(SERIAL_PORT + 2, 0xC7);
    
    // 5. 设置 MODEM
    outb(SERIAL_PORT + 4, 0x0B);
}
```

### 3.2 详细解释

#### 步骤1：禁用中断 (IER)

```c
outb(SERIAL_PORT + 1, 0x00);
```

IER (Interrupt Enable Register) 控制哪些事件触发中断：
- Bit 0: 接收数据中断
- Bit 1: 发送空中断
- Bit 2: 线路状态中断
- Bit 3: MODEM状态中断

写入 0x00 = 禁用所有中断（使用轮询模式，更简单）

#### 步骤2：设置波特率

波特率 = 通信速度（每秒传输的位数）

```
实际波特率 = 基准时钟 / 除数
115200 = 115200 / 1
```

```c
outb(SERIAL_PORT + 3, 0x80);  // 设置 DLAB=1
```

**DLAB (Divisor Latch Access Bit)** 是 LCR 的最高位：
- DLAB=1：访问波特率除数寄存器
- DLAB=0：访问普通数据寄存器

```c
outb(SERIAL_PORT + 0, 0x01);  // DLL = 1 (低字节)
outb(SERIAL_PORT + 1, 0x00);  // DLM = 0 (高字节)
```

除数 = 0x0001 = 1，所以波特率 = 115200

#### 步骤3：设置数据格式 (LCR)

```c
outb(SERIAL_PORT + 3, 0x03);  // LCR = 0000 0011
```

LCR (Line Control Register) 位定义：

| 位 | 名称 | 值 | 含义 |
|----|------|----|------|
| 0-1 | WLS | 11 | 8位数据 |
| 2 | STB | 0 | 1位停止位 |
| 3 | PEN | 0 | 无校验 |
| 4 | EPS | 0 | - |
| 5 | SP | 0 | - |
| 6 | BC | 0 | 无Break |
| 7 | DLAB | 0 | 访问数据寄存器 |

0x03 = 8数据位 + 1停止位 + 无校验 = **8N1**

#### 步骤4：启用 FIFO (FCR)

```c
outb(SERIAL_PORT + 2, 0xC7);  // FCR = 1100 0111
```

FCR (FIFO Control Register)：
- Bit 0: 启用 FIFO
- Bit 1: 清空接收 FIFO
- Bit 2: 清空发送 FIFO
- Bit 6-7: 触发阈值 (11 = 14字节)

0xC7 = 启用FIFO + 清空缓冲区 + 14字节阈值

#### 步骤5：设置 MODEM 控制 (MCR)

```c
outb(SERIAL_PORT + 4, 0x0B);  // MCR = 0000 1011
```

MCR (MODEM Control Register)：
- Bit 0: DTR (Data Terminal Ready)
- Bit 1: RTS (Request To Send)
- Bit 2: OUT1
- Bit 3: OUT2 (必须设置才能产生中断)
- Bit 4: Loopback模式

0x0B = DTR + RTS + OUT2 = 准备就绪，允许中断

## 4. 发送数据

### 4.1 检查发送缓冲区

```c
static int serial_is_transmit_empty() {
    return inb(SERIAL_PORT + 5) & 0x20;
}
```

LSR (Line Status Register) 第5位：
- 1 = 发送缓冲区为空，可以发送
- 0 = 发送缓冲区满，需要等待

### 4.2 发送单个字符

```c
void serial_putc(char c) {
    // 等待发送缓冲区为空
    while (serial_is_transmit_empty() == 0);
    
    // 写入数据寄存器
    outb(SERIAL_PORT, c);
}
```

**流程图：**
```
开始
  ↓
检查 LSR 第5位
  ↓
是 0? ──→ 继续等待 ─┐
  ↓ (是1)           │
写入 THR            │
  ↓                 │
结束 ←──────────────┘
```

### 4.3 发送字符串

```c
void serial_puts(const char* str) {
    while (*str) {
        serial_putc(*str++);
    }
}
```

## 5. 格式化输出实现

### 5.1 整数转字符串 (itoa)

```c
static void itoa(int value, char* str, int base) {
    char* ptr = str;
    char* ptr1 = str;
    char tmp_char;
    int tmp_value;
    
    // 处理负数
    if (value < 0 && base == 10) {
        *ptr++ = '-';
    }
    
    ptr1 = ptr;
    
    // 逐位转换（逆序）
    do {
        tmp_value = value;
        value /= base;
        *ptr++ = "0123456789abcdef"[tmp_value - value * base];
    } while (value);
    
    *ptr-- = '\0';
    
    // 反转字符串
    while (ptr1 < ptr) {
        tmp_char = *ptr;
        *ptr-- = *ptr1;
        *ptr1++ = tmp_char;
    }
}
```

**示例：itoa(123, buf, 10)**

| 步骤 | value | tmp_value | 余数 | *ptr | str |
|------|-------|-----------|------|------|-----|
| 1 | 123 | 123 | 3 | '3' | "3" |
| 2 | 12 | 12 | 2 | '2' | "32" |
| 3 | 1 | 1 | 1 | '1' | "321" |
| 4 | 0 | - | - | '\0' | "321\0" |
| 反转 | - | - | - | - | "123" |

### 5.2 可变参数

```c
typedef __builtin_va_list va_list;
#define va_start(v, l) __builtin_va_start(v, l)
#define va_end(v) __builtin_va_end(v)
#define va_arg(v, t) __builtin_va_arg(v, t)
```

这是 GCC 内置的可变参数支持，类似于标准库的 `<stdarg.h>`。

### 5.3 printf 实现

```c
void serial_printf(const char* fmt, ...) {
    va_list args;
    va_start(args, fmt);
    
    char buffer[32];
    
    while (*fmt) {
        if (*fmt == '%' && *(fmt + 1)) {
            fmt++;
            switch (*fmt) {
                case 's':
                    serial_puts(va_arg(args, char*));
                    break;
                case 'd':
                    itoa(va_arg(args, int), buffer, 10);
                    serial_puts(buffer);
                    break;
                case 'x':
                    serial_puts("0x");
                    itoa(va_arg(args, int), buffer, 16);
                    serial_puts(buffer);
                    break;
                case 'c':
                    serial_putc((char)va_arg(args, int));
                    break;
                case '%':
                    serial_putc('%');
                    break;
                default:
                    serial_putc('%');
                    serial_putc(*fmt);
                    break;
            }
        } else {
            serial_putc(*fmt);
        }
        fmt++;
    }
    
    va_end(args);
}
```
