# 串口输出模块实现计划

## 需求澄清

为操作系统内核添加串口输出功能，用于调试信息打印。串口比VGA更实用，因为：
- 可以在QEMU/Bochs中重定向到文件或终端
- 不需要图形界面
- 支持 printf 风格的格式化输出

## 实现步骤

### Step 1: 串口硬件初始化
**文件**: `oskernel/drivers/serial.c` (新建)

```c
// 初始化 COM1 串口 (端口 0x3F8)
void serial_init();
```

**要点**:
- 设置波特率 115200
- 8数据位，1停止位，无校验
- 禁用中断（轮询模式）

### Step 2: 字符输出函数
```c
// 发送单个字符
void serial_putc(char c);

// 发送字符串
void serial_puts(const char* str);
```

### Step 3: 格式化输出 (printf)
```c
// 简易版 printf，支持 %s %d %x %c
void serial_printf(const char* fmt, ...);
```

### Step 4: 集成到内核
**修改**: `init/main.c`
- 在 `kernel_main()` 开头调用 `serial_init()`
- 替换 VGA 输出为串口输出

### Step 5: QEMU/Bochs 配置验证
- QEMU: `-serial stdio` 参数
- Bochs: 配置 `com1` 输出到文件或终端

## 硬件端口说明

| 端口 | 用途 |
|------|------|
| 0x3F8 | COM1 数据寄存器 |
| 0x3F9 | 中断使能 |
| 0x3FB | 线路控制 |
| 0x3FC | MODEM控制 |
| 0x3FD | 线路状态 |

## 依赖关系

```
serial_init() ──→ kernel_main() 入口调用
serial_printf() ──→ 后续所有调试输出
```

## 风险与注意事项

| 风险 | 级别 | 应对 |
|------|------|------|
| 串口初始化失败 | LOW | 添加超时检查，失败回退到VGA |
| 格式化输出缓冲区溢出 | MEDIUM | 使用固定大小缓冲区(256字节) |
| 可变参数使用错误 | LOW | 参考标准 va_arg 实现 |

## 预计复杂度: LOW

- 串口初始化: 30分钟
- 字符输出: 20分钟
- printf实现: 1小时
- 集成测试: 20分钟
- **总计: 2-3小时**
