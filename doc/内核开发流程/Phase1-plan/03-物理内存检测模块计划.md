# Phase 1 - 物理内存检测模块开发计划

## 1. 任务概述

**目标**: 实现操作系统物理内存检测和管理模块，包括 BIOS E820 内存映射获取和基于位图的物理内存管理器(PMM)。

**重要性**: 内存管理是操作系统的核心功能，为后续的进程管理、虚拟内存、文件系统等提供基础。

### Step 2: 实现 BIOS E820 内存检测 (setup.asm) (1小时)

**任务内容**:
- 在 setup.asm 中添加 `detect_memory_e820` 函数
- 使用 INT 0x15, AX=0xE820 获取内存映射
- 处理 E820 调用失败的情况（使用 0x88 备选方案）
- 将结果写入物理地址 0x1100

**关键技术点**:
- E820 调用约定：EDX='SMAP', EBX=0(首次), ECX=20
- 16位实模式下的寄存器间接寻址（避免符号扩展问题）
- 条目数量使用 32 位存储

**输出文件**:
- 修改 `oskernel/boot/setup.asm`

**验收标准**:
- [ ] E820 调用成功获取内存映射
- [ ] 备选方案(0x88)在 E820 失败时正常工作
- [ ] 内存映射表格式正确（count + entries[]）

### Step 3: 实现物理内存管理器 (C代码) (1.5小时)

**任务内容**:
- 实现 `print_memory_map()` - 打印内存映射表
- 实现 `get_total_memory_mb()` - 计算总内存大小
- 实现 `pmm_init()` - 初始化物理内存管理器
- 实现 `pmm_alloc_page()` - 分配一页物理内存
- 实现 `pmm_free_page()` - 释放一页物理内存
- 实现 `pmm_get_free_pages()` - 获取空闲页数

**关键技术点**:
- 位图法内存管理（每页1bit，0=空闲，1=已用）
- 页帧号(PFN)与物理地址的转换
- 从 1MB 开始管理（低内存保留给 BIOS/内核）
- 位图存放在 0x20000（128KB处）

**输出文件**:
- `oskernel/kernel/mm/mem_detect.c`

**验收标准**:
- [ ] 能正确解析 E820 内存映射
- [ ] 位图初始化正确标记已用内存
- [ ] 页分配/释放功能正常
- [ ] 边界检查完善（防止越界访问）

## 5. 关键技术要点

### 5.1 E820 内存映射格式

```
Offset  Size    Description
0       8       Base Address (物理基地址)
8       8       Length (长度)
16      4       Type (类型)

Type:
  1 = Usable (可用内存)
  2 = Reserved (保留)
  3 = ACPI Reclaimable
  4 = ACPI NVS
  5 = Unusable
```

### 5.2 16位实模式寻址陷阱

```nasm
; 错误：直接寻址会被符号扩展
mov [0x1100], eax    ; 实际访问 0xFFFF8000！

; 正确：使用寄存器间接寻址
mov bx, 0x1100
mov [bx], eax        ; 正确访问 0x1100
```

### 5.3 位图内存管理

```
页大小: 4KB (4096字节)
页帧号(PFN): 物理地址 >> 12

位图索引计算:
  idx = pfn - start_pfn
  bitmap[i] 的 bit j 对应第 (i*32 + j) 页
  i = idx / 32
  j = idx % 32
```

## 6. 风险与应对

| 风险 | 可能性 | 影响 | 应对措施 |
|------|--------|------|----------|
| E820 调用失败 | 中 | 高 | 实现 0x88 备选方案 |
| 内存映射表溢出 | 低 | 中 | 限制最大条目数为32 |
| 位图区域冲突 | 低 | 高 | 选择 0x20000 作为位图地址（内核后） |
| 16位寻址错误 | 高 | 高 | 使用寄存器间接寻址 |
