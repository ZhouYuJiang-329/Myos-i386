# 栈与函数调用

## 寄存器说明

| 寄存器 | 名称 | 作用 |
|--------|------|------|
| `rsp` | Stack Pointer | 栈顶指针，始终指向栈的最顶部 |
| `rbp` | Base Pointer | 帧指针，指向当前函数栈帧的底部 |

> 栈从**高地址**向**低地址**增长（向下增长）

## 函数调用完整过程

以 `main()` 调用 `add()` 为例：

```c
int add() {
    int a = 10;
}

int main() {
    add();
    return 0;
}
```

---

### 阶段 1：main 函数中，准备调用 add()

```
高地址
  +------------------+
  | main 的局部变量   |
  +------------------+
  | main 的 rbp ─────┼── rbp = 0x7fffffffe100
  +------------------+
  |                  |
  |  (空闲栈空间)     |
  |                  |
  +------------------+
  |                  |
  +------------------+
  |                  |
  +------------------+
  |                  |
  +------------------+ ← rsp = 0x7fffffffe0d0
低地址
```

---

### 阶段 2：执行 call add，进入 add()

`call` 指令自动将**返回地址**压入栈中。

```
高地址
  +------------------+
  | main 的局部变量   |
  +------------------+
  | main 的 rbp      |
  +------------------+
  |                  |
  +------------------+
  | 返回地址          |  ← call 自动压入
  +------------------+ ← rsp = 0x7fffffffe0c8 (rsp -= 8)
  |                  |
  +------------------+
低地址
```

---

### 阶段 3：执行 push %rbp

保存调用者（main）的帧指针。

```
高地址
  +------------------+
  | main 的局部变量   |
  +------------------+
  | main 的 rbp      |
  +------------------+
  |                  |
  +------------------+
  | 返回地址          |
  +------------------+
  | 旧的 rbp (main)  |  ← push %rbp 压入，值 = 0x7fffffffe100
  +------------------+ ← rsp = 0x7fffffffe0c0 (rsp -= 8)
  |                  |
  +------------------+
低地址
```

---

### 阶段 4：执行 mov %rsp, %rbp

建立 add 函数的新栈帧，rbp 指向当前栈顶。

```
高地址
  +------------------+
  | main 的局部变量   |
  +------------------+
  | main 的 rbp      |
  +------------------+
  |                  |
  +------------------+
  | 返回地址          |
  +------------------+
  | 旧的 rbp (main)  |  ← rbp 和 rsp 都指向这里
  +------------------+ ← rbp = rsp = 0x7fffffffe0c0
  |                  |
  +------------------+
低地址
```

---

### 阶段 5：执行 movl $10, -4(%rbp)

在栈帧内分配局部变量 `a = 10`。

```
高地址
  +------------------+
  | main 的局部变量   |
  +------------------+
  | main 的 rbp      |
  +------------------+
  |                  |
  +------------------+
  | 返回地址          |
  +------------------+
  | 旧的 rbp (main)  |  ← rbp = 0x7fffffffe0c0
  +------------------+
  | 局部变量 a = 10  |  ← rbp - 4 = 0x7fffffffe0bc
  +------------------+
  |                  |
  +------------------+ ← rsp = 0x7fffffffe0c0 (rsp 没变)
低地址
```

> 注意：局部变量分配在 `rbp` 下方，`rsp` 不变。

---

### 阶段 6：执行 pop %rbp

恢复调用者（main）的帧指针。

```
高地址
  +------------------+
  | main 的局部变量   |
  +------------------+
  | main 的 rbp      |  ← rbp 恢复为 0x7fffffffe100
  +------------------+
  |                  |
  +------------------+
  | 返回地址          |
  +------------------+ ← rsp = 0x7fffffffe0c8 (rsp += 8)
  |                  |
  +------------------+
低地址
```

---

### 阶段 7：执行 ret，返回 main

`ret` 指令弹出返回地址，程序回到 `call` 之后的位置。

```
高地址
  +------------------+
  | main 的局部变量   |
  +------------------+
  | main 的 rbp ─────┼── rbp = 0x7fffffffe100（完全恢复）
  +------------------+
  |                  |
  +------------------+
  |                  |
  +------------------+ ← rsp = 0x7fffffffe0d0（回到 call 之后）
  |                  |
  +------------------+
低地址
```

---

## 指令变化总结

| 指令 | rbp 变化 | rsp 变化 | 说明 |
|------|----------|----------|------|
| `call add` | 不变 | `-8` | 压入返回地址 |
| `push %rbp` | 不变 | `-8` | 压入旧帧指针 |
| `mov %rsp, %rbp` | `= rsp` | 不变 | 建立新栈帧 |
| `movl $10, -4(%rbp)` | 不变 | 不变 | 分配局部变量 |
| `pop %rbp` | 恢复旧值 | `+8` | 恢复帧指针 |
| `ret` | 不变 | `+8` | 弹出返回地址 |

---

## 函数序言与尾声

### 函数序言（Function Prologue）

每个函数开头的标准模式：

```asm
pushq   %rbp          # 保存调用者的帧指针
movq    %rsp, %rbp    # 建立当前函数的栈帧
```

### 函数尾声（Function Epilogue）

每个函数结尾的标准模式：

```asm
popq    %rbp          # 恢复调用者的帧指针
ret                   # 返回调用者
```
